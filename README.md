# ECHORA — official website

Static site for ECHORA (Pre-Alpha 0.1). No build step: open `index.html`.

- Download link: `assets/js/config.js` → `DOWNLOAD_URL` (the only place to change it)
- Text in English and Persian: `assets/js/content.js`
- Styles: `assets/css/site.css`, fonts (Inter, Vazirmatn, SIL OFL) in `assets/fonts`
- Images are real frames from the game build.

Hosted with GitHub Pages from the `main` branch root.
