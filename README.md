# ECHORA — official website

Static site for ECHORA (Pre-Alpha 0.5). No build step: open `index.html`.

- Version, download files and sizes: `assets/js/config.js` (mirrors the game's `package.json` version)
- Web version of the game: `play/` (generated by `scripts/publish-web.mjs` in the game repo; the service-worker cache name carries the version)
- Teaser: `assets/media/echora-teaser.mp4` (montage of real in-game captures)

- Downloads are served from `downloads/` in this repo (Windows portable `.exe`, Android `.apk`). Links and file facts: `assets/js/config.js`
- Text in English and Persian, plus the update log (`updates`): `assets/js/content.js`
- Styles: `assets/css/site.css`, fonts (Inter, Vazirmatn, SIL OFL) in `assets/fonts`
- Images are real frames from the game build (`assets/img`).

Hosted with GitHub Pages from the `main` branch root.
