# Site Analysis — Faculty of Physical Education, Tehran (District 6)

Interactive architectural site-analysis board. Plain HTML / CSS / SVG / JavaScript, no build step, no dependencies: open `index.html` (works from `file://` too).

- `js/data/geo.js`, `js/data/images.js` — generated by `tools/prepare.py` from the v1 project (local metres, origin 35.7065N 51.3930E).
- `js/data/content.js` — photo inventory, streets, sources (from the v1 docs; nothing invented).
- `js/core/sa.js` — SVG / geometry helpers · `js/components/components.js` — MapViewer, LayerControl, Legend, Tooltip, ImageViewer, Navigation, Scrolly, Donut.
- `js/sections/*.js` — one composition per chapter (20 chapters).
- Design tokens in `css/tokens.css`. Fonts: Inter + Vazirmatn (SIL OFL).
