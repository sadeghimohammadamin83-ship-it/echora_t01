# مطالعات شهری رامسر — گروه سوم (مبانی برنامه‌ریزی فضاهای شهری)

| فایل | محتوا |
|---|---|
| `Ramsar_Database.xlsx` | پایگاه داده (21 شیت): منابع، جمعیت، سرانه‌ها، استانداردها، خدمات، گردشگری، تاریخ، جغرافیا، اقتصاد، مقایسه، تعارض‌ها، Lynch، مسائل، نیازها، راهبردها، برنامه، نقشه‌ها، شیت‌های A2، جمع‌بندی، DATA GAP |
| `report.html` | گزارش کامل فارسی (DATA → … → DESIGN) |
| `gis/ramsar_osm_services.py` | تولید نقشه‌های خدمات Map 1–10، سرانه و پوشش بافر از OpenStreetMap |
| `build/` | داده خام (`data.py`) و اسکریپت‌های ساخت Excel و HTML |

بازسازی: `cd build && python3 build_xlsx.py && python3 build_html.py`

هر عدد: منبع + سال + محدوده (City/County/…) + سطح اعتبار (🟢 🔵 🟡 🟠 🔴 ⚪).
